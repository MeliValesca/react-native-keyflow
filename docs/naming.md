# Naming

Selected working name: **react-native-keyflow**. The list below records the initial alternatives.

These are creative suggestions; npm, GitHub, and trademark availability have not been checked.

| Name                         | Why it fits                                                                              |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| react-native-keyform         | Suggests shaping the keyboard, clear and distinctive                                     |
| react-native-keyflow         | Pairs naturally with App & Flow and suggests fluid typing                                |
| react-native-keyskin         | Communicates visual customization, but could imply reskinning the actual system keyboard |
| react-native-keycraft        | Emphasizes custom design and implementation                                              |
| react-native-keys            | Short and straightforward, but broad                                                     |
| react-native-custom-keyboard | Descriptive working name; less distinctive                                               |

Suggested positioning: “Native feel. Your keyboard design.” Avoid “the native keyboard, fully customizable,” which implies access to the system implementation.
