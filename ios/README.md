# iOS

Keyflow is an Expo Modules view wrapping a UITextField with a custom UIKit inputView. The keyboard handles its keys natively. The React component resolves themes and observes events.

Opaque themes use a custom input view for UIKit keyboard presentation. Transparent themes use a clear input surface with the keyboard as its accessory so the app background remains visible. Only the panel background clips its corners; key callouts can extend above the panel.
